Create `playwright.config.ts` with the exact matrix required by FND-07/FND-08 — four projects, desktop and mobile, each in both directions:

    import { defineConfig, devices } from '@playwright/test';

    const baseURL = process.env.PLAYWRIGHT_TEST_BASE_URL ?? 'http://localhost:3000';

    export default defineConfig({
      testDir: './tests/visual',
      fullyParallel: true,
      forbidOnly: !!process.env.CI,
      retries: process.env.CI ? 2 : 0,
      workers: process.env.CI ? 1 : undefined,
      reporter: [['list'], ['html', { open: 'never' }]],
      expect: {
        toHaveScreenshot: {
          animations: 'disabled',
          caret: 'hide',
          scale: 'css',
          threshold: 0.2,
        },
      },
      use: {
        baseURL,
        trace: 'on-first-retry',
        reducedMotion: 'reduce',
        locale: 'en-GB',
        timezoneId: 'Africa/Cairo',
      },
      projects: [
        { name: 'desktop-ltr', use: { ...devices['Desktop Chrome'], viewport: { width: 1440, height: 900 } } },
        { name: 'desktop-rtl', use: { ...devices['Desktop Chrome'], viewport: { width: 1440, height: 900 }, locale: 'ar-EG' } },
        { name: 'mobile-ltr', use: { ...devices['Pixel 7'] } },
        { name: 'mobile-rtl', use: { ...devices['Pixel 7'], locale: 'ar-EG' } },
      ],
      webServer: {
        command: 'npm run build && npm run start',
        url: baseURL,
        reuseExistingServer: !process.env.CI,
        timeout: 180_000,
      },
      snapshotPathTemplate: '{testDir}/__screenshots__/{projectName}/{testFilePath}/{arg}{ext}',
    });

Non-negotiable settings and why — do not "simplify" them:
- `reducedMotion: 'reduce'` globally. The Playwright default is `'no-preference'`, which lets the CI runner's OS setting leak into baselines.
- `{projectName}` in `snapshotPathTemplate`. Without it, a Windows dev run overwrites the Linux CI baselines.
- `scale: 'css'` (default) so hi-dpi runners do not double baseline resolution.
- `locale` and `timezoneId` pinned, because they affect number/date formatting and therefore layout.
- No `maxDiffPixels` / `maxDiffPixelRatio` yet: start strict. Relax only with a documented, measured reason.

Create `tests/visual/gallery-scaffold.spec.ts` as a harness self-test that proves the runner works end to end before real gallery content exists:

    import { test, expect } from '@playwright/test';

    test('harness captures a page in every project', async ({ page }) => {
      await page.goto('/');
      await expect(page.locator('h1')).toBeVisible();
      await expect(page).toHaveScreenshot('harness-scaffold.png', { fullPage: true });
    });

Generate the four baselines on this machine to prove the harness works, then note in the SUMMARY that these are provisional: the real baselines must be regenerated in the CI container because font rendering differs by OS.

Do NOT write `middleware.ts` — Next 16 renamed the convention to `proxy.ts` and a file named `middleware.ts` is silently never called. Phase 1 needs no proxy; Phase 2 adds one.
