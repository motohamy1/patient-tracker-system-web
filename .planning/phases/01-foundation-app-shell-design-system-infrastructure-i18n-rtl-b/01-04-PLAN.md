<objective>
Wire the app-wide reduced-motion policy through a single Motion primitive layer, and wire the Supabase browser client with no privileged credential reachable from client code.
</objective>

Purpose: FND-05 requires reduced-motion-aware motion primitives; FND-09 requires Supabase wiring without exposing privileged credentials. Both are cheap to get right in the foundation and expensive to retrofit across 25 phases. The Motion provider must exist in this phase because every later primitive inherits its behavior.
Output: A single `MotionConfig reducedMotion="user"` provider, a small set of motion primitives with internal reduced-motion branches, an ESLint guard preventing bypass, the Supabase browser client, and a bundle-level test proving no secret key reaches the client.
</objective>

    import { motion, useReducedMotion } from 'motion/react';
    import { fade, pressScale, revealUp } from './variants';

`Fade` — opacity only; safe as-is under reduced motion (opacity animations are preserved by `reducedMotion="user"`). Use it for loaders and content swaps.

`RevealUp` — swap the transform for opacity when reduced motion is on:

    export function RevealUp({ children, className }: { children: React.ReactNode; className?: string }) {
      const shouldReduceMotion = useReducedMotion();
      return (
        <motion.div className={className} {...(shouldReduceMotion ? { initial: { opacity: 0 }, animate: { opacity: 1 } } : revealUp)}>
          {children}
        </motion.div>
      );
    }

`PressScale` — drop `scale` under reduced motion (keep the transition for color/opacity feedback):

    export function PressScale({ children, className }: { children: React.ReactNode; className?: string }) {
      const shouldReduceMotion = useReducedMotion();
      return (
        <motion.button type="button" className={className} {...(shouldReduceMotion ? { whileTap: {} } : pressScale)}>
          {children}
        </motion.button>
      );
    }

`ExpandCollapse` — under reduced motion, use an instant state change instead of an animated height. Add a comment stating that `layout`-driven indicators (the Phase 4 active tab underline, the Phase 6 folder peek) become instant jumps under reduced motion — this is correct behavior that must be designed for, not a bug to fix later.

Add a file-header comment stating the rule: components outside `src/components/motion/` must not import `motion/react` directly; they compose these primitives instead. Task 3 enforces it with a lint rule.

Note: `useReducedMotion` cannot run in a Server Component, which is precisely why every primitive here is a client component and why the boundary is kept at this layer rather than at each usage.

Notes:
- `createBrowserClient` is ALREADY a singleton — do not add a manual cache or `useMemo` guard; that would be dead weight.

- `NEXT_PUBLIC_*` values are inlined at `next build` time, so this file can never read a non-prefixed variable. That is the mechanism, not an accident.

Create `src/lib/supabase/server.ts` with the documented `createServerClient` shape reading the same two `NEXT_PUBLIC_*` names plus cookies from `next/headers`.
