    `## 2. Two-layer architecture` — state the locked split. Framer Motion (the `motion` package) owns component entrance and exit, layout transitions, panels, sheets, folder-to-workspace transitions and compact micro-interactions. GSAP owns complex SVG drawing, timeline path animation, timeline choreography and scrubber-driven progressive rendering, scoped via `gsap.context()` / `useGSAP()`. Write the rule plainly: never both for one animation; do not automatically reach for both libraries on every animation. Name the owning phases so later work knows the boundary: Phase 002 establishes the motion foundation, Phase 006 owns the timeline choreography.

    `## 3. Reduced-motion contract` — state that this is a written invariant, not an aspiration. Every animation routes through `useReducedMotion` in Framer Motion and `gsap.matchMedia('(prefers-reduced-motion: reduce)')` in GSAP. Under reduced motion: degrade to an opacity-only transition at or below the `duration.fast` value, or render statically for timeline choreography. State the check: an animation without a reduced-motion branch fails Phase 002's acceptance, and the visual QA rules file captures a `reduced-motion` baseline state for every visual-regression surface.

    `## 4. Character of motion` — write: all motion is fast, smooth, subtle, interruptible and purposeful; never gamified (§9). Motion must never be decorative — it either communicates a state change, preserves spatial continuity, or explains a transition. No bounce, no overshoot past the target, no attention-seeking loops. The visual grammar is a calm clinical workspace, so motion duration stays at or below `duration.slow` everywhere.
