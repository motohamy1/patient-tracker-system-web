# Plan 02-11 — The Playwright visual-regression harness, the committed baselines, and the phase gate

Build the harness Phase 001 specified and did not write, capture the full baseline matrix against a production build, add the three automated security assertions the phase's threat surface requires, and close the phase against the 12-row visual QA gate and the `INV-xx` registry.

Output: the Playwright config, two spec files, 48 committed baselines, and the two phase acceptance artifacts.
