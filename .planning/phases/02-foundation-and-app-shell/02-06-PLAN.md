# Plan 02-06 — The motion foundation, `Pill`, `TabBar` and `CompactControl`

## Objective

Centralize motion so no component can declare its own duration or curve, then build the three interactive primitives that carry the phase's status, navigation and compact-control vocabulary.

Purpose: FOUND-05 requires that all shell-level motion be fast, smooth, subtle, interruptible and fully reduced on request. That is only enforceable when there is exactly one place the durations live and exactly one hook every animation site calls. `TabBar` and `CompactControl` also carry the phase's two hardest visual facts: status must never be hue-only, and compact navigation must stay a pill strip on mobile rather than collapsing.

Output: `src/lib/motion.ts`, three primitives, and four test files including the reduced-motion contract test.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Status data → rendered pill | A tone identifier decides which tint paints a decorative dot. If the tone ever came from untrusted content, the correct rendering would still be a decorative tint plus a `textPrimary` label, never the tint as the meaning. |
| Generated motion constants → animated elements | Every duration and curve a component animates with resolves through `src/lib/motion.ts` to the frozen token values; a locally declared number would be a third value outside the token source. |
| User preference (`prefers-reduced-motion`) → rendered motion | The OS-level preference is the only environment input in this plan, and it is the one that must be honored without exception. |
| Component markup → assistive technology | The tab strip, the toggles and the search field are keyboard and screen-reader surfaces; a missing role, state or accessible name is a shipped accessibility defect. |
